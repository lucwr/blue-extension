# Icons

Drop the following PNGs here before publishing:

- `icon-16.png` (16×16)
- `icon-32.png` (32×32)
- `icon-48.png` (48×48)
- `icon-128.png` (128×128)

`manifest.json` references these paths. During development, Chrome will fall back
to its default puzzle-piece icon if these are missing — that does not block the
extension from loading.
